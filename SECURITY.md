# Security Policy

PassiveCaptcha is a research prototype and is not yet recommended for production. The README's **Security notes** lists the known gaps.

## Reporting a vulnerability

Please report security problems privately through [GitHub Security Advisories](https://github.com/skdas20/PassiveCaptcha/security/advisories/new), not as public issues.

Bypasses of the detection itself (a bot that gets classified as human) are welcome as regular issues, because they help improve the models. Please include the tool and approach you used.
